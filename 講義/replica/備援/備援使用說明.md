# 備援使用說明（給講師與助教）

2026-11-11 製作。用途：某組卡住、且會影響必保成果（手機操作入口、每組至少一位收到 LINE）時，讓該組從下一個任務接續。

## 使用原則
- 卡住 3 分鐘以上，由助教先判斷原因；確定來不及才用備援。
- 用了備援的組別，在交接紀錄標記「該階段未獨立完成」。不冒充現場成功，也不拿備援畫面當作學員成果。
- 換上前先保存原本的內容：試算表不刪；Apps Script 原程式全選複製，貼到另一個新檔「原程式_備份.gs」。
- 登入、授權、部署、金鑰、發送 LINE 仍由帳號本人操作，助教不代按。

## 落後在哪裡、用哪一份
| 落後的任務 | 用這份 | 換上後接續 |
|---|---|---|
| 任務二～五（照片、建表、修正、檢查） | `備援/青禾食品_2027年度計畫_備援.xlsx` | 第二天任務六（或當天任務五的驗收） |
| 任務六、七（日曆同步） | `GAS存檔點/分段/存檔點A_任務六、七_日曆同步.gs` | 任務八 |
| 任務八（觸發） | `存檔點B_任務八_觸發.gs` | 任務九 |
| 任務九、十（操作入口） | `存檔點C_任務九、十_操作入口.gs` ＋ `GAS存檔點/index.html` | 任務十一、十二 |
| 任務十二、十三（LINE 測試與綁定） | `存檔點D_任務十二、十三_LINE測試與綁定.gs` | 任務十四 |
| 任務十四（每日提醒） | `存檔點E_任務十四_完整版.gs` | 全流程回看 |

每一份存檔點都包含前面所有段落，所以只要換上落後那一段就好，不用一段一段疊加。

## 匯入備援試算表（本人操作，約 5 分鐘）
1. 打開任務一建立的課程資料夾，按「新增 → 檔案上傳」，選 `青禾食品_2027年度計畫_備援.xlsx`。
2. 雙擊打開上傳的檔案，按「檔案 → 另存為 Google 試算表」。
3. 把新的 Google 試算表改名為「【公司名稱】2027年度計畫」。專屬日曆會沿用這個檔名。
4. 核對「任務清單」：9 筆任務、11 個欄位，日期顯示為 2027/03/31 格式，狀態欄有下拉選單。
5. 部門分頁如果顯示錯誤，不影響第二天的程式（程式只讀「任務清單」）。可以請 Claude 依講義任務三，把部門分頁改用 FILTER 公式重建。
6. 原本的 .xlsx 檔留著也沒關係；之後的操作都用另存出來的 Google 試算表。

## 換上 Apps Script 存檔點（本人操作，約 5–10 分鐘）
1. 從本組試算表按「擴充功能 → Apps Script」，確認左上專案名稱是本組的專案。
2. 保存原程式：原本的程式碼全選、複製，新增一個檔案「原程式_備份.gs」貼上。
3. 點左側鬧鐘圖示「觸發條件」，把舊的觸發逐列按「⋮ → 刪除觸發條件」。避免舊觸發指向已經不存在的函式。
4. 打開「程式碼.gs」，按 Ctrl＋A 全選後貼上存檔點全文，再按 Ctrl＋S 儲存。
5. 存檔點 C 以後：左側「＋ → HTML」，名稱填 `index`，貼上 `GAS存檔點/index.html` 全文後儲存（已有 index 就整份取代）。
6. 函式選單選 syncToCalendar →「執行」，依講義任務七完成授權。
7. 存檔點 B 以後：再執行一次 setupTriggers。存檔點 E 會多建立每天 8 點的 LINE 提醒；本人還沒設好 LINE_TOKEN、MY_USER_ID 時，先不要執行。
8. 已經部署過的網頁（操作入口、LINE Webhook）：「部署 → 管理部署作業 → 編輯 → 版本：建立新版本 → 部署」，網址不變。還沒部署的照講義任務九、十三部署。
9. 照講義該任務的「驗收」與「標準答案」核對結果。

## 存檔點和學員現場程式的差異
- 編輯觸發函式名稱是 onTaskEdit（10/18 實測時 Claude 寫的是 onTaskStatusEdit），所以要先刪舊觸發。
- 操作入口是範本介面，沒有任務十的 Skill 美化；功能相同：選負責人、打勾或拖完成度、儲存。
- 綁定成功的回覆多一行「之後的任務提醒會傳到這裡。」
- 存檔點 B～D 的 setupTriggers 只建立 2 個觸發；E 會建立 3 個（多了每天 8 點 LINE 提醒）。
